# 人物形象照（封面用）

把你自己的人物半身照放進這個資料夾，作為**所有 YouTube 封面的人物基準**。

> 目前這裡是空的（只有本說明）。放照片前，封面只能產「不含真人」的主題圖。
> 人物照已在 `.gitignore` 排除，不會進版控。

## 規格建議

- **格式**：PNG（透明去背最佳，白底也可）
- **尺寸**：寬高至少 600px
- **構圖**：半身或 3/4 身，臉部清晰、穿著風格固定（封面才會延續這套穿著）
- **光線**：均勻打光、避免逆光與深陰影
- **數量**：放**一張**就好（gpt-image-2 的 `--edit` 一次只吃一張）

## 放好之後要做的事

1. 檔名自取，例如 `persona.png`
2. 到 `assets/style/cover-style.md` 把「人物（Persona）」段的 `<你的人物照>` 換成實際檔名
3. 生封面時把這張當 reference image：
   - 有內建生圖的 agent（Codex／Antigravity）→ 直接傳給內建工具
   - 沒有內建生圖的 agent（Claude Code／OpenCode）→ `draw.py --edit assets/persona/<檔名>.png`

## 為什麼用參考圖而不是純文字描述？

gpt-image-2 在 `--edit` 模式會延續輸入圖的五官、髮型、穿著。純文字寫「一個戴眼鏡的人」
每次出來的臉都不一樣，做不出頻道識別。

## 鐵則

**每一次生封面都重新讀這張原始照片**，不可以拿上一張生成的封面或任何衍生圖當輸入 ——
模型會放大誤差，越生越不像本人。
