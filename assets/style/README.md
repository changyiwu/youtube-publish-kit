# 封面風格資料夾

放兩個檔案，定義**你的頻道**封面視覺識別。

## 1. `cover-style.md`（必填）

完整的封面風格指南：色票、構圖、字體、主題配色規則、prompt 範本。

目前這份是**模板**，尖括號 `<...>` 的地方都要換成你自己的設定。建議保留結構、換掉內容：

- 整體調性描述
- 背景配色（深 vs 亮）
- 字體選擇（粗黑 vs 圓潤）
- 人物位置（左 vs 右 vs 置中）
- 主視覺類型（icon／截圖／插畫）
- 主題配色規則（你的頻道要不要「主題＝配色」這種規則？）

## 2. `reference-thumbnails.png`（強烈建議，目前未放）

你頻道現有的 9–12 張封面截圖，拼成一張圖。

**為什麼要？** 生封面前 agent 會先讀這張，把你的視覺風格內化，再寫出貼近的 prompt，比純文字描述精準得多。

### 怎麼做

1. 打開你的 YouTube 頻道首頁
2. 截一張 12 格的封面截圖
3. 存成 `reference-thumbnails.png` 放這裡

### 沒有歷史封面怎麼辦

- 新頻道：跳過這檔，靠 `cover-style.md` 的文字描述就夠
- 想參考別人的風格：截別人頻道的封面也行，但要在 `cover-style.md` 註明「希望走 XX 風格」
