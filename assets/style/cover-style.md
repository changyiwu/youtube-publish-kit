# YouTube 封面風格指南（`<你的頻道名>`）

> 此檔是頻道封面的**視覺基準**。所有生封面的 prompt 都依這份寫，頻道識別才會穩定。
>
> **⚠️ 這是一份模板。** 尖括號 `<...>` 的地方請換成你自己的設定；整段改寫也可以，
> 但建議保留「五大固定元素 → 配色規則 → 色票 → 構圖網格 → prompt 範本」這個結構，
> agent 是照這個順序讀的。

## 整體調性

- **一句話定位**：`<例：Tech YouTuber × 教學頻道，高對比、發光特效、強烈呼喚點擊感>`
- **參考氣口**：`<列 2–3 個你希望靠近的頻道視覺語言>`
- **嚴禁**：`<例：純白底、純色平塗、自然風景、生活寫真感>`

## 五大固定元素

### 1. 背景（Background）

- **主色**：`<例：深海軍藍 / 接近黑>`
- **特效**：`<例：放射狀光線、霓虹漸層、粒子、細微網格、資料流線條>`
- **氣氛**：`<例：科技未來感，但靠暖色標題拉回溫度>`

### 2. 主標題文字（Title Typography）

- **字體**：超粗黑體中文字（思源黑體 Heavy／Noto Sans TC Black 等級）
- **主色**：`<例：亮黃 或 白>`
- **描邊**：粗黑色描邊 4–6px，確保任何背景下都清晰
- **特效**：可加輕微漸層或發光，**不要** 3D 立體浮雕字
- **位置**：`<例：左半邊>`，佔畫面寬度 40–50%
- **行數**：2–3 行，每行字數盡量一致
- **字級**：佔畫面高度 1/3 以上 —— 手機縮圖才看得清楚

### 3. 副標題／集數標籤

- **集數標籤**（系列影片用，如 `<你的系列名> EP12`）：位置在標題上／下方，字級較小，白或淺色
- **副標**：描述影片內容，主標下方，白色細字
- **裝飾**：箭頭、橫線、圓點等小圖標分隔

### 4. 人物（Persona）

- **基準照**：`assets/persona/<你的人物照>.png` —— **每次生封面都重新讀這張**，不可沿用舊封面
- **位置**：`<例：畫面右側，佔寬 35–45%>`
- **構圖**：半身或 3/4 身，臉部清晰
- **常見 pose**：雙手抱胸（沉穩）／一手指向主題（教學）／一手攤開（介紹）／雙手呈現產品（強調）
- **打光**：主色系 rim light 打邊緣輪廓
- **嚴禁**：改變五官、髮型、服裝顏色、眼鏡 → 永遠延續基準照

### 5. 主題視覺（Topic Visual）

- 與影片主題對應的圖示／插畫／介面截圖示意，放 `<例：左側中下方>`
- 周圍加發光暈與背景區隔
- 配色與主標、背景呼應

## Prompt 撰寫範本（填空版）

```
YouTube 封面 16:9，<你的頻道名>風格。

背景：<背景主色 Hex> 漸層底，左下與右上有「{THEME_LIGHT_COLOR}」放射光，
細微網格與粒子特效，整體<調性描述>。
※「{THEME_LIGHT_COLOR}」依主題配色規則決定。

人物：畫面<位置>放置這個人，姿勢為「{POSE}」，
<主色> rim light 打在邊緣，臉部表情「{EXPRESSION}」。
※ 人物樣貌、五官、髮型、服裝、配件全部延續輸入的人物基準照，不要更動。

主視覺（<位置>）：{TOPIC_VISUAL}，周圍有發光暈與背景區隔。

文字：
- 集數標籤（左上）：「{SERIES_LABEL}」白色細字
- 主標題（左中）：「{MAIN_TITLE}」<主標色> 超粗黑體中文字，
  粗黑色描邊 4–6px，佔畫面寬度 40–50%，2–3 行排列。
- 副標題（主標下方）：「{SUBTITLE}」白色細字，較小字級。

整體風格：高對比、強烈呼喚點擊感、適合<你的受眾>。
不要：<禁止清單>。
```

填空變數：

| 變數 | 說明 |
|------|------|
| `{THEME_LIGHT_COLOR}` | 依主題配色規則決定 |
| `{POSE}` | 例「雙手抱胸沉穩」「一手指向左側主題」 |
| `{EXPRESSION}` | 例「自信微笑」「專注解說」 |
| `{TOPIC_VISUAL}` | 例「AI 介面正在自動填寫表格」 |
| `{SERIES_LABEL}` | 例「`<系列名>` EP01」，沒有就留空 |
| `{MAIN_TITLE}` | YouTube 標題的精簡版 |
| `{SUBTITLE}` | 副標說明（可選） |

## 生封面 SOP

```
Read assets/style/cover-style.md（本檔）
  → Read assets/style/reference-thumbnails.png（若有）
  → 重新 Read assets/persona/<你的人物照>.png
  → 依主題配色規則決定主色
  → 填好 prompt
  → 依 agent 選路：內建生圖工具，或 skills/cover-image/draw.py --edit <人物照>
```

`--edit` 一次只吃一張輸入圖，所以參考圖只能傳人物基準照；風格靠 prompt 貼近本檔描述來維持。

quality 一律 `low`（夠用、便宜、快），除非要實體印刷才升 `high`。
